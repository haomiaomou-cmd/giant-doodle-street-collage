# giant-doodle-street-collage

**虚实拼贴街景艺术** —— 把一张真实照片变成「绘本怪物闯进现实」的超现实拼贴画。

> 真实照片背景（不动）+ 一个极度放大的扁平涂鸦角色（叠加）+ 物理互动 + 手绘涂鸦漂浮物 + 怪诞留白的表情

## 这是什么

一个视觉风格 Skill。它不给照片套滤镜，而是往真实照片里「派」一个角色进去——一个被极度放大的扁平涂鸦怪物闯进日常街景，用橡皮管四肢、粗黑描边、平涂色块和怪诞表情，制造「巨人入侵日常」的超现实反差。

区别于同类照片重绘风格（那些通常会抹掉背景、重画成纯色纸面），**本风格刻意保留原始照片的真实质感**——建筑、招牌、街道纹理、玻璃反光全部原样不动。真实感是整个画面的地基，失去它反差就消失了。

## 风格六要素

| 要素 | 说明 |
|---|---|
| **虚实拼贴** | 背景保持真实摄影，不重绘、不虚化、不改光线 |
| **巨型尺度** | 角色极度放大，身体常撑满甚至溢出画框，四肢夸张拉长 |
| **物理互动** | 必须与实景接触：手压雨棚、腿垂台阶、戳井盖、泡进水面 |
| **插画语言** | 粗黑描边（手抖越线）、平涂无渐变、橡皮管四肢 |
| **怪诞表情** | 不卖萌：不对称不眨眼空洞凝视、极小瞳点、高低眉、扁平嘴角 |
| **涂鸦留白** | 稀疏漂浮物（歪扭云、眼球、螺旋、看不懂的签名），宁少勿多 |

## 色彩策略

角色用**冷调病态感**撞色，与照片暖调形成冲突：

- 灰紫 `lilac / muted violet` — 冷、疏离
- 病态黄绿 `sickly chartreuse` — 不安感
- 旧珊瑚粉 `dusty coral` — 褪色的温柔

铁律：高饱和平涂，无渐变、无阴影、无高光、无光泽。

## 核心差异点：表情生态

这是本 Skill 与「可爱卡通怪兽」类风格最重要的分界。

**禁止**：微笑、弯眼、圆润可爱、直白的呆萌。

**要做**：不对称、不眨眼的空洞凝视；瞳点极小；高低眉，一只眼大一只眼小；嘴角扁平微张或干脆没有嘴；视线方向「差一点」——看向画外、看向镜头、看向不可能的地方。

目标是让观众说不清它是什么情绪、在想什么。**给联想空间，不给答案。** 好的状态是安静、诡异、说不清的忧郁，像走错片场的绘本怪物。

## 使用方式

把本 Skill 放到你的 AI 助手技能目录（例如 `~/.workbuddy/skills/`），然后：

```
用 giant-doodle-street-collage 把这张照片做成巨人闯入街景
```

或直接提及「虚实拼贴」「巨型卡通角色」「flat doodle collage」触发。

### 迭代指令

| 你说 | 效果 |
|---|---|
| 表情更怪诞 / 更有想象空间 | 加不对称、空洞凝视、取消微笑、缩小瞳点 |
| 肢体再夸张 | 加长手臂/手指，让身体溢出画框 |
| 加涂鸦元素 | 增补漂浮 doodle |
| 换配色 | 替换角色色卡，保持平涂无渐变 |
| 角色换成 XX | 只改角色形态，保留互动点与风格层 |
| 再怪一点 / 更诡异 | 身体局部断裂、溶解，或加「正在注视镜头」的直视感 |
| 做系列 | 锁定色卡、描边、涂鸦语言，只换角色与互动点 |
